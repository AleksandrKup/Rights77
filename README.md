# Rights77 — права 1С 7.7

Настольное приложение для просмотра пользователей, наборов прав и разрешений на объекты информационной базы 1С:Предприятия 7.7.

[Скачать готовый EXE](https://github.com/AleksandrKup/Rights77/releases/latest)

## Возможности

- Поиск пользователей, наборов прав и объектов конфигурации.
- Проверка, кто может читать, изменять или удалять выбранный объект.
- Просмотр содержания набора прав и прав конкретного пользователя.
- Сравнение двух наборов прав или текущей базы с сохранённым JSON-снимком.
- Экспорт матрицы разрешений в CSV и результатов анализа в JSON.
- Диагностика ошибок чтения и неизвестных разрешений.

## Запуск

1. Скачайте `Rights77.exe` из Releases и поместите в доступную для записи папку.
2. Запустите программу и выберите папку информационной базы либо файл `1CV7.MD`.
3. Для просмотра пользователей в этой базе должен присутствовать `USRDEF\USERS.USR`.

Пример проверки: **Кто имеет доступ → Справочник → нужный справочник → Корректировка (редактирование)**.

Программа поставляется одним EXE. Устанавливать 1С, Rust, .NET или Visual C++ Redistributable не требуется. Настройки хранятся в `DataRights77` рядом с EXE. Место сохранения CSV и JSON выбирается при экспорте. Файлы базы в состав программы не входят.

## Совместимость

Сборка предназначена для Windows 7 SP1 x64, Windows 10 x64 и Windows 11. Используется целевая платформа `x86_64-win7-windows-msvc` со статической средой выполнения C/C++. Интерфейс использует OpenGL. 32-битная Windows не поддерживается.

Непосредственный запуск опубликованной сборки на Windows 7 пока не подтверждён; требуется проверка на целевой системе.

## Как определяются права

Приложение читает OLE-контейнеры, метаданные CP1251 и бинарные наборы прав версии 6. Явное правило объекта имеет приоритет над общим правилом его типа. Если подтверждённого значения нет, отображается «Не определено».

Анализируются сохранённые права платформы. Дополнительные ограничения в коде конфигурации не вычисляются. «Корректировка», «Любые изменения» и «Ввод нового» показываются как отдельные действия.

Исходные файлы открываются только на чтение. Пароли и их хеши не сохраняются в модели и экспорте. Сохранение отчётов внутрь исходной базы запрещено.

## Сборка в RustRover

Откройте корень репозитория и выберите конфигурацию:

- **Rights77 — Build Windows 7 + 10 + 11 (x64)** — собрать программу.
- **Rights77 — Build and Run Windows 7 + 10 + 11 (x64)** — собрать и запустить.

Нажмите ▶. Результат: `dist\Rights77.exe`. Общие конфигурации находятся в `.run` и вызывают `Build.ps1` с необходимыми параметрами совместимости.

Для сборки нужны Rust nightly, компонент `rust-src`, Visual Studio Build Tools с инструментами C++ и Windows SDK:

```powershell
rustup toolchain install nightly
rustup component add rust-src --toolchain nightly
.\Build.ps1
```

Для сборки с последующим запуском используйте `.\Build.ps1 -Run`. Первый запуск загружает зависимости и компилирует стандартную библиотеку; повторные сборки используют кэш `target`.

## Проверки

```powershell
cargo fmt --all -- --check
cargo test --all-targets --locked
cargo clippy --all-targets --locked -- -D warnings
```

Основные тесты создают временные файлы и не требуют установленной 1С или готовой базы. Дополнительные тесты на контрольной демобазе включаются переменной `RIGHTS77_TEST_BASE`; требования описаны в [VALIDATION.md](VALIDATION.md).

## Командная строка

Анализ выбранной базы с экспортом в текущую папку:

```powershell
$databasePath = Read-Host 'Путь к информационной базе'
.\dist\Rights77.exe --inspect $databasePath --csv .\rights.csv --json .\snapshot.json
```

## Устройство проекта

- `src` — интерфейс, модели, чтение файлов и экспорт.
- `tests` — интеграционные проверки.
- `assets` — исходники значка, встраиваемого в EXE.
- `.run` — конфигурации RustRover.
- `vendor/windows-link` — библиотека с поправкой импорта `CoTaskMemFree` для Windows 7; её лицензии сохранены.

Версии зависимостей зафиксированы в `Cargo.lock`. Файлы баз, настройки приложения, настройки конкретного экземпляра IDE и результаты сборки исключены из Git.
