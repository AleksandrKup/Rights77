# Права 1С 7.7 — Rights77

Самостоятельное настольное приложение на Rust для просмотра пользователей, наборов прав и разрешений на объекты 1С:Предприятия 7.7. Установленная 1С, COM, GComp, сервер и браузер не нужны.

Готовый EXE: [скачать последнюю версию](https://github.com/AleksandrKup/Rights77/releases/latest). Исходники доступны в этом репозитории; сборка описана ниже.

Версия 0.3.0 собирается одним EXE для Windows 7 SP1 x64 и Windows 10/11. Среда выполнения C/C++ встроена статически. Целевая платформа Rust — `x86_64-win7-windows-msvc`; для сборки требуется nightly с rust-src и MSVC Build Tools. Фактический запуск на Windows 7 ещё требует проверки на целевом компьютере.

## Запуск

Скачайте и откройте `Rights77.exe` из релиза либо `dist\Rights77.exe` после локальной сборки. Выберите папку базы либо файл `1CV7.MD`. Для загрузки пользователей рядом должен находиться `USRDEF\USERS.USR` из той же базы. Последняя папка запоминается в `DataRights77\last-path.txt` рядом с EXE.

Демо-база «Торговля+Склад 9.2» находится отдельно от проекта: `C:\InfoBase7\DemoDB`. В Конфигураторе 1С штатно созданы 4 тестовых пользователя: Тест_Администратор, Тест_Менеджер, Тест_Продавец и Тест_Кассир. Копия базы в проекте не хранится.

## Что доступно

- **Обзор**: конфигурация, число объектов, наборов и пользователей; экспорт CSV и снимка JSON.
- **Кто имеет доступ**: тип объекта → поиск по имени, синониму или ID → объект → действие. Показаны наборы прав, результат и назначенные пользователи. Флажок оставляет только разрешённые.
- **Наборы прав**: все распознанные действия для объектов выбранного набора; поиск и фильтр разрешённых. Наведение на результат показывает исходный поток и правило.
- **Пользователи**: имя, полное имя, набор, интерфейс, каталог; быстрый просмотр редактирования справочников и переход ко всем правам пользователя.
- **Сравнение**: два набора текущей базы либо набор текущей базы и старого JSON-снимка. Можно оставить только различия. Объекты сопоставляются по типу и ID: сравнивайте версии одной конфигурации.
- **Диагностика**: предупреждения чтения и объяснение результатов.

Пример: **Кто имеет доступ → Справочник → Номенклатура → Корректировка (редактирование)**. В проверенной демо-конфигурации разрешено наборам «Администратор», «Менеджер», «Продавец»; запрещено «ОператорККМ».

## Точность и границы

Читаются OLE Compound File, текст метаданных CP1251, контейнеры наборов и бинарные страницы прав версии 6. Прямые правила объекта имеют приоритет; при их отсутствии используется общее правило того же типа с ID=0. Неизвестные значения обозначаются «Не определено», а не «Запрещено». В диагностике показываются объекты, для которых не удалось восстановить имя. Неизвестные коды действий сохраняются в модели и экспорте.

«Корректировка» — исходное действие 0x04, «Любые изменения» — отдельное действие 0x03, «Ввод нового» — 0x05. Это не права восьмой версии. Приложение показывает сохранённые разрешения платформы по назначенному набору, не моделирует дополнительные проверки в модулях, ограничения конкретных форм и состояние документов.

В `C:\InfoBase7\DemoDB\USRDEF\USERS.USR` находятся 4 настоящие учётные записи, созданные через Конфигуратор 1С 7.7. Наборы прав и интерфейсы: Администратор, Менеджер, Продавец и ОператорККМ (для кассира). Пароли не задавались. Искусственные файлы пользователей и их генератор удалены.
## Сборка кнопкой в RustRover

Откройте эту папку как проект. В верхнем списке конфигураций выберите:

- `Rights77 — Build Windows 7 + 10 + 11 (x64)` — собрать один переносимый EXE;
- `Rights77 — Build and Run Windows 7 + 10 + 11 (x64)` — собрать и сразу открыть программу.

Нажмите зелёную кнопку Run. Готовый файл: `dist\Rights77.exe`. Обе конфигурации
вызывают `Build.ps1`, а не обычный `cargo build`, и сохраняют совместимость с Windows 7.
Один и тот же EXE предназначен для Windows 7 SP1 x64, Windows 10 x64 и Windows 11.
32-битная Windows не поддерживается. DLL, .NET и Rust на целевом ПК не нужны.
Настройки программы создаются в `DataRights77` рядом с EXE.

Нужны Rust nightly с rust-src и Visual Studio Build Tools с C++ x64/x86 и Windows SDK.
Для настройки компьютера разработчика:

```powershell
rustup toolchain install nightly
rustup component add rust-src --toolchain nightly
```

Общие конфигурации IDE хранятся в `.run`. Скрипт сам находит библиотеку
windows-targets в Cargo-кэше и встраивает C/C++ runtime статически.
Кэш `target` ускоряет повторные сборки; удалять его после каждой сборки не нужно.

Сборка и проверки вручную:

```powershell
.\Build.ps1
cargo test --locked
cargo clippy --all-targets --locked -- -D warnings
```

Для дополнительной проверки на локальной демо-базе:

```powershell
$env:RIGHTS77_TEST_BASE = 'C:\InfoBase7\DemoDB'
cargo test --locked
```

Готовая переносимая сборка: `dist\Rights77.exe`. Rust нужен только для разработки. Графический интерфейс — eframe/egui; OLE — cfb; CP1251 — encoding_rs. Версии зафиксированы в `Cargo.lock`.

Консольный анализ и экспорт (в debug-сборке вывод виден в терминале):

```powershell
cargo run --locked -- --inspect 'C:\InfoBase7\DemoDB' --csv '.\rights.csv' --json '.\snapshot.json'
```

Встроенная проверка отрисовки: переменная `RIGHTS77_RENDER_DIR` задаёт каталог PNG всех шести вкладок; после сохранения приложение закрывается. Изображения берутся из буфера отрисовки самой программы, без захвата рабочего стола. Не задавайте эту переменную при обычном запуске.

Файлы информационных баз, локальные настройки и кэш сборки в репозиторий не включены. Локальная демобаза нужна только для дополнительных тестов; без неё тесты используют временные тестовые файлы.

Совместимость: локальная копия windows-link 0.2.1 в vendor сохраняет исходную лицензию и меняет только импорт CoTaskMemFree с combase.dll на ole32.dll. Эта функция доступна в Windows 7. rfd зафиксирован на 0.14.1; графический движок — OpenGL/glow.
