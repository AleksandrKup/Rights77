# Проверка Rights77

## Автоматические проверки

Для версии 0.3.0 выполнены форматирование, статический анализ Clippy и 13 тестов. Проверки охватывают:

- Разбор метаданных с кириллицей и экранированными кавычками.
- Чтение контейнеров, записей пользователей и наборов прав.
- Приоритет явных прав над общими правилами типа.
- Обработку неизвестных значений, отсутствующих наборов и повреждённых файлов.
- Отсутствие паролей и хешей в экспорте.
- Экранирование CSV, сериализацию JSON и запрет экспорта внутрь исходной базы.
- Сохранность исходных файлов при чтении.

После рефакторинга модели и имён переменных JSON- и CSV-экспорт контрольной базы побайтно совпали с результатами предыдущей сборки. Ключи JSON `id` и `md_bytes` сохранены для совместимости снимков.

## Контрольная демобаза

Дополнительные тесты включаются явно:

```powershell
$env:RIGHTS77_TEST_BASE = Read-Host 'Путь к контрольной демобазе'
cargo test --all-targets --locked
```

Эти тесты рассчитаны на подготовленную конфигурацию «Торговля+Склад, редакция 9.2» с 264 объектами, четырьмя наборами прав и четырьмя тестовыми пользователями. Они проверяют конкретные контрольные значения, а не произвольную пользовательскую базу. Ожидаемые данные заданы в `tests/integration.rs`; сама база не распространяется.

Для справочника «Номенклатура» подтверждено разрешение корректировки в наборах «Администратор», «Менеджер» и «Продавец» и запрет в «ОператорККМ». Результат просмотрщика сопоставлен с поведением 1С при входе под тестовыми пользователями. Изменения объектов при проверке не сохранялись.

## Графический интерфейс

Проверены загрузка базы, отображение пользователей и прав, поиск, фильтры, сравнение наборов, экспорт и прокрутка. Проект открывается в RustRover; панель ошибок проекта не показывает ошибок.

## Сборка

Опубликованный EXE собран для `x86_64-win7-windows-msvc` со статической средой выполнения C/C++. Проверены системные зависимости и отсутствие зависимости от `combase.dll`, внешнего CRT и .NET. Скачанный из GitHub Releases EXE совпал с исходным файлом по SHA-256.

Непосредственный запуск опубликованной сборки на Windows 7 пока не подтверждён. Проверка отдельных действий не означает проверку всех разрешений, конфигураций и версий платформы.
