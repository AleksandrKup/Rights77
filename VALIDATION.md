# Проверка Rights77

Дата: 10 ноября 2026 года.

На локальной `C:\InfoBase7\DemoDB\1cv7.md` прочитаны 264 объекта, 4 набора, по 277 блоков каждого набора. Все ссылки на объекты получили имена. Отсутствующий `USRDEF\USERS.USR` диагностируется отдельно; число пользователей — 0.

Для Номенклатуры (тип 3, ID 84), права корректировки (код 4): Администратор — 1, Менеджер — 1, Продавец — 1, ОператорККМ — 0. Значения сверены с бинарными блоками потока MD; отдельная ручная сверка через конфигуратор не выполнялась.

Автоматические проверки:

- Текстовая структура: кириллица, вложенность, двойные кавычки, обрезанный/лишний текст.
- Бинарные права: отказ при обрезанном потоке; явное правило, общее правило, неизвестное и неприменимое действие.
- Пользовательская страница: разбор полей, отсутствие хеша в сериализации.
- Полная цепочка OLE-фикстур: пользователи → набор → объект → действие; кириллица и регистр файлов.
- Отсутствие USERS.USR и отказ при некорректном OLE.
- Побайтовая неизменность исходных MD/USR после чтения и отказ записи отчёта внутрь базы.
- CSV: кавычки, кириллица, нейтрализация формул, отсутствие парольного хеша.
- Локальная демо-база: число объектов/наборов, имена, значения Номенклатуры, JSON round-trip.

Пользовательские страницы проверены на синтетических бинарных фикстурах, созданных по изученной структуре. Реальный файл пользователей в предоставленной демо-базе отсутствует, поэтому этот путь требует дополнительной сверки на реальной базе с пользователями.

Визуально проверены шесть экранов через собственный буфер отрисовки eframe. Захват экрана Windows и управление 1С не использовались.
